## Important (all fixed and verified)

1. **[Security] audit/agents/fix-agent.md** — the shell-guard self-test section prescribed
   `GIT PUSH` and `Git Push` as the case-variation cases. Those cannot push: the git binary resolves
   under any casing on a case-insensitive volume, but git subcommands are case-sensitive, so
   `GIT PUSH` fails with "cannot handle PUSH as a builtin". The only real bypass shape is
   `GIT push`. The same wrong claim had been copied into both hook comments and into the previous
   audit log, where it served as the justification for a shipped change. Corrected in all four
   places. The guards themselves were already right: they match case-insensitively.
2. **[Code-Quality] audit/guidelines/code-quality-2026.md** — the section demanded evidence that a
   hook declaration was accepted, "one debug-log run showing the registration line". No worker can
   produce that: the code-quality worker runs as `code-reviewer` with Read, Grep and Glob only, and
   the prompt template requires a trace for every claim-of-absence, so the bar was unreachable and
   every hook concern would have been dropped silently. Reworded to the statically checkable
   declaration shape, with the debug-log run reassigned to the hook's author.
3. **[Code-Quality] full-audit/SKILL.md** — the run_in_background sweep of the previous turn covered
   `/audit`, `/plan-it` and `/live-audit` but missed full-audit entirely: its worker dispatch and its
   finding-verifier dispatch had no flag, although CLAUDE.md already claimed they did.
4. **[Docs] CLAUDE.md** — the eval-cost gotcha still said "29-fixture set" against 54 real fixtures.
5. **[Eval contract] both new expectation files** (round 2) — the fixtures could not discriminate a
   correct finding from a wrong one. Findings must cite `file:line`, so the filename lands on every
   finding line, and both fixture names embedded one of their own scoring keywords ("flat", and
   "exit-1" which becomes "exit 1" after the scorer's hyphen transform). Any wrong finding at the
   right line scored a hit. Fixed by renaming both fixtures to scenario names that carry no
   diagnostic token, with the discriminating power re-proven by pushing a deliberately wrong and a
   deliberately correct finding line through the real scoring chain.
